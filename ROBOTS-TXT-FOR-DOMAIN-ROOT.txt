This file is documentation, not a served robots.txt.

Crawlers read robots.txt only at a domain root. This repository publishes to
https://znorris.github.io/calculators/, so a robots.txt committed here would be
served at /calculators/robots.txt and ignored. It has to live at
https://znorris.github.io/robots.txt, which means committing it to the
znorris.github.io user-pages repository instead.

Copy the block below into that repository as robots.txt. If a robots.txt
already exists there, merge the Sitemap line into it rather than replacing the
file, since it governs every project page on the domain.

----------------------------------------------------------------------
User-agent: *
Allow: /

# Share links carry the user's own figures in the query string. Nothing links
# to them, so a crawler should not reach one, but this makes it explicit.
Disallow: /calculators/*?c=
Disallow: /calculators/*&c=

Sitemap: https://znorris.github.io/calculators/sitemap.xml
----------------------------------------------------------------------

Two things worth knowing about that Disallow.

It is a request, not enforcement. A well-behaved crawler honors it; nothing
stops one that does not, and it has no effect on a link pasted into a service
that fetches URLs to build a preview.

It also only helps while share data lives in the query string. Moving the
payload to a URL fragment would remove the exposure at the source, because a
fragment is never sent to a server and is not indexed as a separate URL. That
change is still open.

Separately, submit the sitemap directly in Google Search Console. That does not
depend on robots.txt and is the faster path to being crawled.
